# Configuração do frontend

Os arquivos HTML desta pasta foram sanitizados para publicação pública.

Antes de conectar o frontend a uma instância real do n8n, substitua:

```text
https://SEU_SUBDOMINIO.app.n8n.cloud
```

pelo endereço da sua própria instância do n8n.

## Arquivos

- `index.html`: painel principal do AutorizaIA.
- `familia.html`: formulário de solicitações da família.

> **Segurança:** não publique endpoints de escrita sem autenticação/controle de acesso em um site público de produção. Os webhooks deste repositório são exemplos de configuração do protótipo.
