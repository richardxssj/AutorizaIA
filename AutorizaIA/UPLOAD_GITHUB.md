# Publicação no GitHub

1. Crie um repositório chamado `AutorizaIA`.
2. Envie **o conteúdo desta pasta**, não o ZIP da entrega escolar.
3. Antes do primeiro commit, pesquise por:
   - qualquer URL real da sua instância n8n
   - `SEU_GOOGLE_SHEET_ID`
   - `SEU_GOOGLE_DRIVE_FOLDER_ID`
   - `credentials`
   - chaves/tokens pessoais
4. Os placeholders `SEU_*` devem permanecer no repositório público.
5. Não envie a planilha original, comprovantes, `.env`, tokens, credenciais ou vídeos grandes.

## GitHub Pages

O `frontend/index.html` pode ser publicado como página estática, mas a versão pública está sem os endpoints reais por segurança. Para uma demonstração online funcional, configure um backend apropriado e proteja os webhooks antes de expor o endereço.
