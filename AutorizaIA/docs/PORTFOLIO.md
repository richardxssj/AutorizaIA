# Materiais da entrega acadêmica

A entrega original do AutorizaIA também possui:

- documentação acadêmica em PDF;
- podcast produzido com ElevenLabs;
- comercial oficial produzido com D-ID;
- comercial adicional produzido com Google Flow;
- planilha e comprovantes usados durante o desenvolvimento.

Esses arquivos não fazem parte desta versão pública do repositório para manter o projeto leve e reduzir exposição desnecessária de dados e mídia.

O código, os workflows sanitizados, exemplos fictícios e screenshots necessários para compreender a solução permanecem neste repositório.
